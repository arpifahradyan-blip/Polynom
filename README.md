# Polynomial Operations & Data Structures in C++

![Language](https://img.shields.io/badge/Language-C%2B%2B-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

A C++ repository featuring implementations of **Polynomial operations** (evaluation, derivatives) alongside custom **Abstract Data Types (ADTs)**, Sets, and C++ Standard Template Library (STL) demonstrations.

---

## 📁 Repository Structure

```text
├── ADT/                             # Abstract Data Type modules
├── Polynom/                         # Core polynomial headers and implementations
├── ADT.cpp                          # ADT testing and demonstration
├── Polynom i arjeq tvyal ketum.cpp   # Polynomial evaluation at a specific point
├── SET.cpp                          # Custom Set data structure implementation
├── STL Stack.cpp                    # C++ STL Stack usage and examples
└── polynom acancyal.cpp            # Polynomial derivative calculation
✨ FeaturesPolynomial Calculus: Calculate derivative operations and evaluate polynomials at specific input values ($x$).Data Structures: Implementations of custom ADTs and Set structures.STL Integration: Practical examples using standard library containers such as std::stack.
🛠️ Build & Run
To compile and run any module using g++ (GCC):
# Example: Compile the polynomial derivative program
g++ -std=c++17 "polynom acancyal.cpp" -o polynom_derivative

# Run the executable
./polynom_derivative
